Cross-device sync

Your server never reads your notes.

Notes are encrypted on your machine with a key derived from your passphrase (scrypt + Fernet) before they leave it. The sync server stores ciphertext only. File names stay visible; contents do not.

Laptop

plaintext, on your disk

Sync server

sees ciphertext only

Desktop

decrypted with the same passphrase

The orange chip is one note travelling between devices.
